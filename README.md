# Promotion Dizad — المتجر الإلكتروني

متجر **Promotion Dizad** للباكات الكهرومنزلية في الجزائر: الدفع عند الاستلام، والتوصيل متوفر إلى 55 ولاية.

- 🌐 المتجر الحي: https://promotiondizad.github.io
- 📘 صفحة فيسبوك: https://www.facebook.com/promotion.dizad
- 💬 الطلب عبر واتساب من داخل المتجر مباشرة

## بنية المستودع

| المسار | الوصف |
|---|---|
| `index.html` | صفحة المتجر (GitHub Pages) — تُنشر تلقائياً عند كل دفع إلى `main` |
| `telegram-opencode-bot/` | سكربت جسر تيليغرام لـ OpenCode على هاتف المدير (UserLAnd) — لا علاقة له بعرض المتجر، وبقاؤه هنا لأن رابط تحميله المباشر معتمد في الهاتف |

## التحديث

تُحدَّث المنتجات والأسعار في `index.html` وتُدفع إلى فرع `main`، فينشر GitHub Pages النسخة الجديدة خلال دقائق.
